# Проектирование сервиса уведомлений о статусах заказов

## 📝 Описание проекта
Модуль системы маркетплейса, обеспечивающий получение изменений статусов от внешнего сервиса доставки и отправку Push-уведомлений пользователям в мобильное приложение.

---

## 🎯 Требования (User Stories & NFR)
- **US-1:** Как покупатель, я хочу получать push-уведомления об изменении статуса заказа, чтобы своевременно узнавать о его доставке.
- **US-2:** Как покупатель, я хочу получать уведомления только по своим заказам, чтобы быть уверенным, что информация относится именно ко мне.
- **NFR-1:** Система должна отправлять push-уведомление не позднее 2 секунд после получения информации об изменении статуса.
- **NFR-2:** Система должна поддерживать не менее 10 000 одновременно работающих пользователей.
- **NFR-3:** Передача данных между внешним сервисом и маркетплейсом должна осуществляться по протоколу HTTPS.
- **NFR-4:** Push-уведомления должны быть доступны только авторизованному пользователю, которому принадлежит заказ.
